# 宋玉 · 抖音账号主页设置

文件在 `样片/账号/`：
- 头像三款（1080×1080，抖音会裁成圆形）；
- 主页头图一张（1125×633）。

## 一、头像

| 款 | 样子 | 建议 |
|---|---|---|
| **A 黑底（推荐）** | 黑底，米白色“宋玉”，下面一道红线 | 缩到最小（评论区、私信列表里）也认得出；和视频里黑底“人物”标签呼应 |
| B 米白底 | 米白底，黑字“宋玉” | 和视频底色一致，但在白色界面里边缘不明显 |
| C 印章 | 红底白字竖排“宋玉”，宋体 | 有辨识度，但缩小后笔画糊，不建议做主头像 |

字体是思源黑体 / 思源宋体（SIL OFL），可以商用。

## 二、主页头图

米白底，居中写“宋玉”，下面是“从一条新闻，看清一门生意”，再下面三个标签：人物 / 资讯 / 产业链。

文字都放在中间偏上，避开左下角头像压住的位置。

## 三、昵称和抖音号

- **昵称**：宋玉。如果被占用，就用“宋玉说商业”或“宋玉商业观察”。不要加“财经”“老师”这类词，跟人设不符。
- **抖音号**：可以改一次，建议用好记的拼音，例如 `songyu_biz`（以平台实际可用为准）。

## 四、简介（三选一，可以直接复制）

**版本 1：短而清楚（推荐）**
```
从一条新闻，看清一门生意。
人物｜资讯｜产业链
只用公开资料：公告、年报、交易所文件、当年报道。
每周更新
```

**版本 2：突出人设**
```
一条不起眼的新闻背后，往往是一整条产业链。
我把公告、年报、旧报道翻一遍，替你拼出来。
人物｜资讯｜产业链 · 每周更新
```

**版本 3：突出可信**
```
宋玉 · 商业观察
所有结论都附原文出处，说错欢迎指正。
人物｜资讯｜产业链
```

写简介时注意：
- **不写**“我在现场”“内部消息”这类话（身份保护，也和“只用公开资料”的人设冲突）。
- “每周更新”要能做到再写，做不到就去掉。
- 先不留联系方式，粉丝多了再加商务邮箱。

## 五、主页上的其他标签

- **性别、生日、地区、学校**：都不填（身份保护）。
- **合集**（主页会显示）：
  - 「宋玉 · 人物」
  - 「宋玉 · 资讯」
  - 「宋玉 · 产业链」
- **系列话题**：`#宋玉人物` `#宋玉资讯` `#宋玉产业链`，每条视频带上对应的一个。
- **置顶视频**（最多 3 条）：先置顶第一条人物视频；以后人物、资讯、产业链各置顶一条最好的。
- **橱窗、团购**：先不开。
