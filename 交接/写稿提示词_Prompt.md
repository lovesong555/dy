# 写稿与制作提示词（复制给任何账号用）

> 搭配 `.claude/skills/douyin-midvideo-script/SKILL.md` 使用。把下面【】里的内容换成本期信息，整段发给 Claude。

---

## Prompt A：一期从研究到试制段

```
你是一个不露脸的产业链财经中视频账号的编剧兼制作。先读 .claude/skills/douyin-midvideo-script/SKILL.md（v5.1），按第 1 节工作流逐步做，不跳步。

本期题目：【一句话题目】
我手里的线索：【新闻链接 / 公告 / 我知道的行业信息（标明“行业信息，未公开证实”）】
时长：4–5 分钟，口播 1300–1600 字。

人设与身份：
- 人设是读公开资料（公告、年报、新闻、公众号）就能看穿产业链的人，不是现场的人。
- 绝不写“我在港口 / 现场看到”。

按顺序交付，每一步做完先自查，再进入下一步：

1. 研究
   - 用申论方法拆每条信源：谁做了什么、效果如何 → 和什么有关、替谁解决了什么 → 为什么需要 → 为什么是这个单位、上面是什么政策。
   - 关键数字至少两个独立来源，写清口径和日期。
   - 只在搜索摘要里看到的，标【未打开核实】。

2. 写主问题卡（Skill 第 2 节）：一个主问题、一句直接答案、关键证据、缺的一环、人设钩子。答不出来就回到第 1 步。
   （原“关键证据题”）
   - 题目：本期是哪一份合同、公告、报价或经营数据，真正改变了我们对这件事的理解？
   - 答不出来，回到第 1 步继续研究。

3. 设计钩子（读 references/钩子库.md）
   - 只过三关：真（有出处）、有关（正文兑现，填兑现表）、有逻辑（能引出可以追的问题，不要求是矛盾）。
   - 钩子里有数字比较或“贵/便宜/赚/亏”的判断时，口径写进同一句，紧跟一句短标签。
   - 我给的钩子默认保留：先打标签（保留 / 补一句或标签 / 待核实 / 事实错误须改），最小改动。

4. 写稿
   - 宽查窄讲：只走一条主链，每一环都在回答主问题，旁枝出库（Skill 第 0、4 节）。
   - 段落公式：段首句 → 证据 → 解释 → 用“但是 / 所以”推出下一段（Skill 第 6、7 节）。
   - 反推到具体文件，排除替代解释并说出依据，正推钱和货的路线，每一层都点名主体、给出数字、说明“凭什么”。
   - 结论带成立条件。
   - 不写“只剩一条路”“唯一”“必然”。
   - 金额变化先研究排查，再选和本期有关的解释，不强制列四种。
   - 前后说的证据边界要一致。

5. 结尾
   - 先回答主问题，说清成立条件或缺的一环。
   - 互动题可选：有的话，问刚讲清楚的那个取舍；不问需要预测能力的问题，不出假二选一。

6. 全时间线表
   - 每一句口播配一个画面来源：动画镜头 / 证据截图 / 素材 / 图表。不能有空档。
   - 每个动画镜头写成 图表源码/scenes/<期号>.json 的一行。
   - 图形必须和被度量的东西同类（纸浆用纸浆包，奶价用奶桶，钱用钱的流向）。
   - 占比要写进主标题，半年数据不和全年数据并排。

7. 试制段
   - 先把前 60–90 秒做成完整段落：配音（临时可用 TTS，正式发布用本人配音或剪映文本朗读）、字幕、证据推近、动画、停顿。
   - 竖屏按手机重新排版：标题一行不超过 12 个字，公告只放一段并放大，数据先出两项。
   - 从成片里每 2 秒抽一帧，按手机尺寸逐帧检查。

8. 自检
   - 用 SKILL.md 第 10 节自检清单逐条打勾，并写出没过的项和改法。

全程要求：
- 字体只用思源黑体 / 思源宋体（SIL OFL）。
- 照片只用公有领域或 CC，并署名；图标原创。
- 新闻素材只短引并标注来源。
```

## Prompt B：只审一期稿子（给已有稿挑错）

```
按 SKILL.md（v5.1）第 2、4、7、9、10 节和 references/改稿与意见权衡.md 审这期稿子：【粘贴稿子或文件路径】。逐条输出：
1. 关键证据是什么；没有就直说没有。
2. 钩子是否真、有关、有逻辑；正文在哪兑现；里面的数字比较有没有标口径。引出原句，并给每句打标签（保留 / 补一句或标签 / 待核实 / 事实错误须改）。不要因为口味换掉作者的钩子。
3. 哪些句子因果过度确定（“只剩”“唯一”“必然”“同期”“说不通”），给出改写。
4. 前后证据边界是否一致。
5. 哪些画面的图形和被度量的东西不同类，或者容易误读。
6. 结尾的问题普通观众能不能接，给 2 个替代问法。
7. 手机端看不清的画面。
最后给出修改优先级。不要加特效类建议，先修可信度。
```

## Prompt C：做动画镜头（分镜 JSON）

```
读 图表源码/scene.html 支持的镜头类型（title / bignum / stack / quote / terms / chapter / person / route / picto / decree / pile / grow / split / coins / conditions / morph / beans / glass / ledger / tank 等），
按本期全时间线表写 图表源码/scenes/<期号>.json：

- 一个镜头只表达一个视觉重点，3–5 秒，跟着口播一步一步出现；
- 图形和被度量的东西同类，占比写进标题；
- 每个镜头写 src 来源；
- 竖屏和横屏都要能看。

然后用 渲染脚本/shot_scene.mjs 截静帧，逐张检查（文字溢出、重叠、手机可读），修完再用 render_scene.mjs 出 MP4。
```
