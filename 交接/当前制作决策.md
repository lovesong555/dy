## 1. 本期（第08期）到底解释哪个问题

**废纸进口这条路关上之后，玖龙为什么选择把原料做进自己公司（自建木浆），这个选择付出了什么代价。**

- 张茵的生平只用来**引入**：她是谁、这条家族废纸链是怎么来的。
- 政策只是**转折点**：2021 年起禁止进口固体废物。
- 产业分析是**主线**：四条可选的路，为什么钱压在自建上，代价是什么，采购额下降有四种可能。

三者不抢主线。

## 2. 采用什么形式（各自负责什么）

| 画面元素 | 负责什么 | 什么时候用 | 不用在哪 |
|---|---|---|---|
| **原文截图**（`proof`） | 证据：政策原文、交易所公告、旧报道 | 每个关键事实第一次出现时 | 不拿来当装饰背景 |
| **物件 / 简笔画**（`compose`、`options`、`triad`、`pile`、`grow` 等，图标库 `icons.js`） | 过程：原料怎么变成纸、货怎么走、量多量少 | 解释材料、运输、成本时 | 不用跨类比喻（不能拿纸张表示奶价） |
| **人物**（`person`，赛璐璐插画） | 决策者、出资人、后果承担者是谁 | ① 第一次介绍；② 讲到张茵认购永续债时（人物 → 资金 → 公司） | 讲政策、讲原料转化、讲成本涨跌时不出现。规则见 Skill 13.12 |
| **关系图 / 卡片**（`options`、`maybe`、`choice`、`conditions`） | 选择和推理：几条路、几种可能、成立条件、决策题 | 中后段 | — |
| **风格** | “档案纸”版式（纸 #EFE9DD、墨 #2A2522、朱红 #C8372D）；横屏为母版，竖屏用同一引擎原生输出；字体只用思源宋体 / 思源黑体 | 全片 | 毛玻璃深色数据图降为备选，横转竖外框作废 |

## 6. 下一步只交付什么

**只交付：第08期试制段（横版 + 竖版）。**里面有配音、字幕、原文截图、拆解链、人物各一处，并附这份决策记录。

**验收标准**（找一个没研究过这个题的人用手机看）：
1. 看完能说清：这段在解释“一个卖废纸的家族，为什么开始卖木头 / 自己造浆”；
2. 反差建立在同一份公告的措辞上，不跨口径；
3. 手机上能读清三处关键证据：港交所“木片协议”、2006 年“八成原料”、四部委“禁止以任何方式进口”；
4. 每个画面都在增加理解。拿掉人物，第一次介绍会缺信息；其余镜头里没有人物。

**需要用户集中看一次的只有两件事**：
- 用哪个人物形象（赛璐璐版 / 剪影版 / 改为原创绘制）；
- 整段节奏是否合适（97 秒）。

其余按本记录继续，不用逐条确认。

**验收通过以后的顺序**：
1. 按同一流程补完第08期后半段，包括人物 → 资金 → 公司的永续债镜头；
2. 第04期按“关键证据题”做试制段；
