## 第01期 韩国二手车经烟台去中亚

**主问题卡**
- 主问题：韩国的二手车，为什么要绕道中国的铁路去中亚？
- 类型：原因
- 直接答案：海路受阻、俄罗斯的转口规则收紧之后，“韩国 → 烟台 → 铁路 → 中亚”给了它一条更近的陆路。**新的不是这条通道**（它 2021 年就开了），**而是用铁路笼车运二手车这种组织方式**。
- 关键证据：烟台港 2026-09 的通稿（滚装 + 笼车）；韩国二手车出口月均下降 28%；俄罗斯报废费规则的变化。
- 缺的一环：这批车是否转口俄罗斯，没有证据，明说。

**主链**：
1. 车怎么走（滚装 → 换装笼车 → 霍尔果斯）；
2. **所以**谁在买、买的是高价准新车；
3. **但是**为什么是现在：海路堵了、规则变了，于是有了笼车这种新运法；
4. **所以**中国在这笔生意里赚的是什么：港口装卸、换装、铁路运费。

**旁枝出库**：
- 利比亚均价、蒙古通道、2019 年自贸区方案：只留一句，或者移到证据库。
- 哈萨克斯坦的新车份额：不再作为全片的核心矛盾，最多在结尾用一句。

**最需要改的地方**
1. **开头的核心矛盾不成立。**原句：“中国车卖得这么好，为什么还有人千里迢迢运韩国旧车？”新车份额高，和有人买进口二手车，本来就能共存。
   - 改：用一个细节开题，例如“烟台港 9 月的通稿里有一个词：铁路笼车。韩国的二手车，第一次装进笼车穿过中国。”
2. **“为什么偏偏是2026年才冒出来”和后文“2021年7月就开了”自相矛盾。**
   - 改：把问题改成“为什么今年开始用笼车运二手车”，并在问题一里就交代“通道早就有，新的是运法”。
3. **对象来回切**：哈萨克斯坦 → 吉尔吉斯斯坦 → 利比亚 → 俄罗斯 → 中东 → 蒙古。
   - 改：一次只讲一个国家。每个国家的数据只用来回答当前这一环。
4. **结尾的决策题**（阿拉木图买车选哪台）和主问题（为什么绕道中国）无关。
   - 改：结尾回答主问题；不需要互动题的话，可以不放。

## 第02期 挖掘机：南美价格、蓬莱航线、紫金金矿

**主问题卡**
- 主问题：南美正在需要的这些工程机械，需求从哪来？
- 类型：原因
- 直接答案：圭亚那、苏里南的基础设施投资和矿山扩建同时在加速（政府预算、紫金扩建），设备跟着项目出去。
- 关键证据：海关稿“服务中国企业在圭亚那、苏里南承建的……基础设施项目”；圭亚那 2026 年预算；紫金扩建公告。
- 缺的一环：航线上的货和紫金之间没有公开对应，明说（已改）。

**主链**：
1. 一张误导性的价格对比（入口，≤20 秒，已改）；
2. **所以**真正要追的是需求：航线去了哪；
3. **所以**那边在干什么：修路、建电厂、扩矿；
4. **但是**设备到那边以后，价格里还有运费、关税、售后。只有拿到可比报价才讲；拿不到就一句带过。

**旁枝出库**：
- “国内几年前同级新机五六十万”对比“阿根廷现在 109 万”：仍然不同期，删掉。
- 山东出口全国第二、出口和内销各占一半：拔高段可以压到一句。

**最需要改的地方**
1. **价格论证还没真正结束。**问题三“就算新机比新机，南美贵在哪”，用的仍然是“几年前”的国内价格。
   - 改：删掉这个对比，把问题三改成“设备到了那边，靠什么才能用起来”（运输、关税、售后网点），只讲有原文的部分。
2. **三条线争时间**（设备需求、紫金投资、价格构成）。
   - 改：以“需求从哪来”为主线，紫金是其中一个需求方，价格只是入口。

**最需要改的地方**

   - ✅ 已改为：“选择在海边整体造好、直接装船，是更合算的交付方式：少拆少装、少在工地上焊。”下一稿还要补充港口、吊装、焊接条件各起什么作用的原文证据。
3. **结尾超出了正文能证明的范围**：“订单多、利润降”不能推出“这笔中东订单利润薄”。

## 第04期 一家卖牛奶的，为什么买巴西大豆

**主问题卡**
- 主问题：一家做牛奶的公司，为什么要和粮商签 6 年的巴西大豆协议？
- 类型：原因 / 选择
- 直接答案：豆粕是奶牛的蛋白饲料，饲料是原奶成本的大头；长期协议锁定的是**来源和数量**，零毁林是它另外加的条件（自身目标和出口要求）。**没有看到定价条款，不能说已经锁定了成本。**
- 关键证据：中粮 2025-05-29 新闻；现代牧业 2024 年业绩（每公斤原奶的饲料成本）；蒙牛 2030 零毁林目标。

**主链**（调整顺序，先讲关系）：
1. 豆粕进入奶牛饲料；
2. **所以**饲料决定原奶成本（77%，**原奶**生产成本）；
3. **但是**奶价在跌，**所以**企业要稳住饲料来源；
4. **但是**为什么偏要零毁林：这是另一个理由；
5. 150 万吨放进中国进口总量里有多大。

**旁枝出库**：中国大豆进口总量、关税的细节，压到一句。

**最需要改的地方**
1. ✅ **确定的错误，已改**：原句“这盒奶四分之三的成本是饲料，饲料的蛋白，八成以上靠进口”扩大了两次：原奶成本被说成盒装奶成本，大豆进口依赖被说成全部饲料蛋白的进口依赖。
   - 已改为：“养牛产奶这一步，四分之三的成本是饲料；豆粕是饲料里的蛋白来源之一，而中国的大豆大部分靠进口。”
2. **顺序**：开头问“大豆和牛奶什么关系”，但约一分钟后才讲豆粕喂牛。
   - 改：把“豆粕进入饲料”提到第一环。
3. **三个结论要分开说**：签长期协议、控制采购价、零毁林采购，不是同一件事。

## 第06期 美国等变压器

**主问题卡**
- 主问题：美国为什么要等两年多才拿到一台大型电力变压器？
- 类型：原因
- 直接答案：需求增长（电网更新、新能源、数据中心）撞上扩产慢（大型产品的产能、取向硅钢、熟练工人、认证周期）。
- 关键证据：WoodMac 的交期数据；美国能源部、NREL 的供应链报告；中国海关出口数据。
- 缺的一环：中国企业能接哪些型号、交期多长，要按同等级产品比较；没有可比数据就不下结论。

**主链**：
1. 交期多长（只讲**美国大型电力变压器**）；
2. **所以**需求从哪来；
3. **但是**为什么扩产慢（产能、材料、人员、认证之间的关系，不停在“只有一家硅钢厂”）；
4. **所以**中国企业能承接哪一部分（按地区和型号说清口径）。

**最需要改的地方**
1. ✅ **“只对了三分之一”已删**：列了三个原因，不能换算成贡献比例。
2. ✅ **开头“还有一样东西排队排得更久”已改**：没有芯片的交期数据，不跟芯片比交期，只说“抢芯片的同时，变压器也在排队”。
3. ✅ **结尾“中国工厂3到6个月就能交”已改**：这是不同等级、不同条件下的交期，和美国大型电力变压器不可比。改为“不同等级的产品交期差别很大，能不能替代，要看具体型号”。
4. **口径混用（待改）**：
   - 美国本土供给占比、中国出口均价、大功率产品，可能各自是不同统计范围。
   - 下一稿逐个标明口径，口径对不上的不要放在一起比。

## 第07期 李一男和小牛

**主问题卡**
- 主问题：创始人不在董事和高管名单上，他和小牛现在是什么关系？
- 类型：关系
- 直接答案：他是一只信托的受益人，这只信托通过两家公司持有小牛 41.9% 的 A 类股，是第一大股东。投票权怎么安排、谁在管经营，要分开说。
- 关键证据：SEC 20-F（董事、高管名单）；13D/A（41.9% 的 A 类股、增持）。
- 缺的一环：
  - 信托的保护人怎么行使权利；
  - A 类股占总投票权的比例，要在 20-F 里核对 A / B 类股的投票安排，核对前不说“四成股份”。

**主链**：
1. 他当年是谁（≤30 秒）；
2. **但是**现在名单上没有他；
3. **所以**往下翻持股：信托 → 两家公司 → 41.9% 的 A 类股；
4. **所以**这层关系意味着什么：持股、受益权、投票权、经营管理，分别由谁掌握。

**旁枝出库**：
- 港湾、百度、12580、案件细节：压缩到 30 秒。
- 自游家退款：留一句，作为“他还在创业”的旁证。

**最需要改的地方**
1. ✅ **开头“很多人对骑电摩的年轻人印象不太好”已删**：和股权主线没有解释关系，还给一群人贴了标签。改为从“名单上没有他，但持股表里有他”开题。
2. ✅ **结尾“他不在公司上班，却握着公司四成的股份”已改**：41.9% 是 A 类股，不是总股本；不在高管名单，也不等于不在公司上班或不参与经营。改为“他不在董事和高管名单上，但他是受益人的信托，持有 41.9% 的 A 类股”。
3. **篇幅**：现在约 2 分钟在讲早年经历，和选题卡“30 秒带过”不符。下一稿按主链重排。
