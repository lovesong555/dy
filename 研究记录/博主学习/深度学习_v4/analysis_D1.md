## 1. 逐期逻辑骨架（压缩版）

记号：**[前提]→[证据]→[推断]→[转折]→[结论]**。“反推”指从一个反常事实倒推原因，“正推”指从原因推出后果。

### 1.1 巫师财经

**巫1 双十一（2019）**
- 起点数据：成交额 5200万 → 191亿 → 1207亿 → 2135亿。
- 0:37 先给结论：“双十一就像是每年一度的排位赛，可以给每位消费者的智商和阶级定序”。
- 公理前提：资本逐利。由此推到价格歧视：“相同的东西卖给不同的人价格不一样”。
- 拆出难点（1:50）：“最大困难就是区分谁是富人，谁是穷人”。双十一就是这个筛选器。
- 证据是一个算例：同一副 5000 元耳机，A/B/C/D 四类人分别花 4500 / 4800 / 6000 / 15000 元。
- 反直觉的推论（4:50）：“没参加和不关心这个行为本身就已经帮资本给他们定了序”。
- 主动抛出反问（5:42）：“这价格歧视怎么还干好事了呢？”回答：“资本是没有立场的”。
- 第二机制：比较成本。“搜同款”把价格压到利润下限，双十一的复杂规则又人为把比较成本抬了上去，于是（10:22）“双十一是信息技术进步的经济学倒退”。
- 收尾：对特价学区房给出五问清单，再用沉没成本给行动建议。

**巫2 日本经济崩盘（2020）**
- 0:22 立靶子：“广泛流传的说法……有很强的误导性，我会逐个击破”。
- 时间线是一条因果链：战后通胀 → 美国扶植（冷战，失去中国）→ 朝鲜特需（52亿，同期美援不到20亿，“这场战争贡献一目了然”）→ 窗口指导。
- 对窗口指导先讲纪录片的批评，再说“我持保留态度”，理由是重工业“对于资本来说费力不讨好”。
- 泡沫成因：美国滞胀 → 加息 → 汇率上升 → 逆差 → 施压日本金融自由化 → 广场协议。
- 关键转折（15:40）：“广场协议不是日本经济崩盘的根本原因……真正导致崩盘的是日本自己”，依据是自由化、宽松、减税、“自杀式加息”2.5% 到 6% 这一串操作。
- 落到一户人的账（18:00）：首付 300 万、贷款 700 万，房子跌到 500 万后，“首付300万没了，房子也没了，还多了200万欠款”，并补一句“这是极端情况”。
- 处理阴谋论（24:20）：“有点脸谱化……资本金字塔的每个层级都是危机的受害者，但也是推进者”。
- 点名谁买单（25:10）：“老实本分的普通人，凭什么为金融系统的疯狂和错误埋单？”
- 收尾“辩证看”：不良率降到 2% 以下、买的次贷最少、企业转向上游。

**巫3 关税（2025）**
- 先算边际：叠加后关税 105–115%，但“65%和115%差别不大了……边际效应递减”。
- 反推“为什么只有中国反击”：“他们和美国没有终局之战”。
- 重新定义（3:20）：“关税反击并不在于反击本身，而是你一定会反击的姿态”；“本质……就是看哪个经济体更能吃苦”。
- 比例对照：欧洲只反制 280 亿美元，而美国对欧征税范围近 6000 亿，“你还是不敢双输”。
- 历史分母：美国有效关税在 1930 年是 15–20%，中金预测这次会到 25% 以上。
- 正推后半段（补转写部分）：流动性收紧 → 利润 → 就业 → 税收 → 财政。代入决策者（9:37）：“如果我是trump，我就会继续用更激进的关税手段……毕竟我就这四年”。
- 点名谁买单（10:33）：“关税本质上是让消费者们来买单……累退性”，最低 20% 人群可支配收入降 4%，最高 10% 只降 1.6%。
- 结论（11:40）：“真正阻碍美国重塑制造业的障碍……很可能是民主本身”，因为这类政策整体收益为正，但各群体的收益天差地别。
- 缺点：前半段情绪化表述多，比如“伪装成国家的公司”、欧洲的“姥爷病”。

**巫4 特斯拉（2025）**
- 先换算：YU7 18 小时锁单 24 万辆，“对应至少608亿收入”。
- 先立再破（2:20）：“这个叙事是不是听起来特斯拉很亏，恰恰相反”。分明面和水下两层讲。
- 水下这层：2018 年产能陷阱等于现金流断裂。建厂时间对比：美国 3–4 年、欧洲 2–3 年，上海 9 个月建成、11 个月下线首车，成本“低一倍以上”。
- 金句（5:10）：“特斯拉完成了0到1，而中国帮助特斯拉完成了1到100”。
- 让步（7:25）：“当然有人会说……建立在极致的性价比上。确实如此”。接着说二三十万价位特斯拉仍然登顶。
- 给“质变”下定义：“不是效率和成本的反超，而是全体系的反超”，再分六个维度举证。
- 选观测节点（12:20）：“在二三十万红海价位和特斯拉硬刚，这才是真正的近身肉搏”。
- 收尾“市场换技术，是强者的砒霜，但是弱者的武器”，后段民族叙事过热。

**巫5 睡眠（2026）**
- 先重新定义：“躺在床上闭上眼睛8个小时”不等于好觉。
- 用分母对比制造反差：OSA 患者 2 亿，诊断率美国约 20%、中国不到 1%。
- 反推为什么被忽视，列四个原因：观念、基层医生、就医路径、保险。
- 排除法：手术长期有效率 40–60%；约 50% 的患者和肥胖无关；香薰枕头之类是玄学。所以“只有呼吸机……是确定性方案”。
- 用资本市场做证伪：减肥药“末日论”让股价从近 300 跌到 136，后来发现用减肥药的患者呼吸机依从性反而高 10.5%，因为他们“更频繁就医，更容易被筛查”。
- 估算市场时给出分母和限定：2 亿 × 19% ≈ 3800 万，“当然这只是乐观估计”。
- 列催化剂：药监批了适应症，2026 年出了诊治指南。
- 最后一转（8:50）：“这本不应该是一个巨大的商机，这是一个公共卫生体系和认知的失效”。

**巫6 外卖（2025，4 分钟）**
- 用成本收益解释社会行为：“不是你撞的，你为什么扶？”→ 猜忌链：“行善的代价巨大……几乎没有收益”→ “需要额外的收益机制来对冲成本”。
- 证据只有三个奖励案例，没有反方意见，公关感明显。

**巫7 运营商（2026）**
- 剪刀差开场：“用户增长曲线昂扬向上，而利润的增长曲线却近乎水平”。
- 用价值链解释利润去哪了（1:05）：“运营商修好了路……但路上的车……和车里的货……都不属于他们”。
- 拆成隐痛和剧痛：隐痛是管道化；剧痛是换机周期从 18 个月拉长到 30–40 个月，“签约的机会减少了一半”。
- 结构性的“为什么是它”（2:40）：“不同于可以通过出口来寻找增长点的制造业，运营商的业务高度依赖于本地人口规模”。
- 类比推理：汽车是“大号手机”，那“小号的下一代手机是什么？”答案是眼镜。
- 解释为什么投这家：“他们不需要再扶持一个黑马，他们需要一个能立刻大规模出货……的白马”。

### 1.2 温义飞

**温1 江西（2024，3:28）**
- 先否定刻板印象：“这个评价根本就不对”。
- 带分母的对比：房地产投资占比全国 27%、江西 14%。
- 反推原因是“开放”：铁路历史上绕开江西；别省“用全省的力量去建设一个城市”，江西却向外靠。理由（2:06）：“你就算把南昌建设的再好……边上就是江浙沪……那怎么能比呢”。
- 内部对照做证据：和外省联动好的上饶、赣州、抚州增速 5% 以上，南昌慢一点。
- 后半段转去讲地域精神，偏弱。

**温2 民办大学（2023）**
- 悖论开场：毕业生找不到工作，大学却还在扩招。
- 反推到政策：2016 年修订的民办教育促进法放开了营利，在校生增量逐年 +12万、+20万、+60万、+80万。
- 用上市公司报表证明利润：净利率 40%、65%。
- 正推收入链：学费 → 杂费 → 按人头补贴 → 便宜的教育用地（楼叫“国际交流中心”，其实是酒店）→ 人流 → 商业 → 住宅 → 融资 → 扩张，“用学生把土地养肥”。
- 结尾用反讽收：“21世纪最贵的是人才”。

**温3 预制菜（2023）**
- 跨界替代类比：“淘汰小偷的不是警察叔叔，而是手机支付”。
- 中间环节冗余的推理（1:59）：“只是给我热热就送来了，那我自己不会热菜吗？”→ 省掉商家和配送两块成本。
- 解释为什么是现在：冷链、监管、工业化。
- 分价位预测：料理包冲击十几二十块的盒饭，酸菜鱼一类抢 35–50 元的市场。
- 证据弱：“70% 外卖用预制菜”没有说来源。

**温4 四川（2024）**
- 从政策文件切入：国土空间规划给的定位是“战略腹地”。
- 横向对比定位（0:46）：贵州是生态文明试验区，云南是向南开放通道，“再回来感受一下……是什么档次”。
- 给概念下定义（0:55）：“你不一定什么都做的最好，但是你必须什么都不缺”，再按定义逐项清点：粮猪油盐、各城市的工业分工、水电（“每100度水电30度”）、军工。
- 推到机会（2:02）：“国家需要在四川把所有的基础产业重新做一遍，这就是四川未来的机会”。
- “发电量世界第三”这个说法存疑。

**温5 长沙（2023，7:30）**
- 悖论：增速最快，房价却低。
- 带倍数的对照：20 年 GDP 涨 16 倍，深圳 13 倍，上海 6 倍。
- 用比例戳破表象（0:52）：餐饮住宿营收约 500 亿，GDP 1.3 万亿，“这是一个误会”。真底色是工程机械，产值约占全国三分之一。
- 反转常识的因果：制造业强 → 不靠地产 → 房租低 → 有钱消费 → 才有烟火气。
- 拆机制：住宅用地供应 2700 万方对北京不到 700 万方；新建面积年增 8% 对深圳 3%；福利房到 2015 年还占 15%。
- 反问“政府真的吃亏了吗？也没有”，再推二阶效应：人口十年增长 50%。
- 博弈论泛化（4:50）：“第一个这样做的城市肯定能够成功……当所有的城市都学会这个套路之后，这招就无效了。你吸引的人他不是凭空长出来的”，并用辟邪剑谱作比。
- 国际分母：居住用地占比首尔 60%、伦敦 50%，中国 30% 左右。
- 结论（7:07）：“房地产最多是城市发展的兴奋剂……马拉松还是要靠实打实的产业”。

**温6 美国救市（2020）**
- 按时间线推演政策加码：降息 0.5% → 熔断 → 降到 0 加 7000 亿 QE → 再熔断 → 无限 QE → 2 万亿。
- 机制类比：“左手借钱给右手”。
- 换标靶（7:24）：“股市是标，就业是本”，然后推恶性循环：失业 → 没钱消费 → 更大失业 → 所以要直接发钱。
- 这是早期作品，梗多、民族情绪重，适合当反例。

**温7 精神病院（2022，三段）**
- 先自曝怀疑：“以为是个假消息，结果一查居然是真的”，再声明不是广告。
- 拿荒谬感检验数字：“300户的小区里面，那不得有40户”，结论是“不但不是瞎说，而且还报的挺保守”，然后解释统计口径。
- 两个对比：治疗缺口（1600 万重症只有 200 万在治）；中美支出“20分之1”。
- 反推“为什么市场大却不赚钱”，给两个原因：住院收入 70% 以上靠医保而医保在控费；病耻感把人推向心理咨询。并对冲一句：“数据有没有被人为的调整，我也不能确定”。
- 价格悖论（6:04）：“越专业的心理咨询，价格反而越便宜了”。原因是医生和咨询师的门槛差异，加上 2017 年官方认证停止。

**温8 县域消费（2026）**

### 2.2 温义飞：悖论开题、政策反推、给普通人可用的结论

1. **用“悖论”开题。** 两个事实同时成立，却互相冲突。

   - 温1：“全国房地产投资占比是27%，而江西只有14%”。
3. **反推到政策节点。** 一个时间点加一条文件。
   - 温2：“2016年……修订的民办教育促进法放开了对盈利性民办教育的限制……从2016年开始，办大学就成了一个合法的生意”。
   - 温4：“国土空间规划……战略腹地”。
4. **先给概念下定义，再按定义清点。** 这是申论里“为什么是它”的标准动作。
   - 温4：“不一定什么都做的最好，但是你必须什么都不缺”。
   - 温8：“非典型县域消费场景……本质就是把一线城市的生活方式搬到县城”。
5. **正推一条收钱链或循环链。**
   - 温2：学费 → 补贴 → 土地 → 人流 → 商业 → 住宅 → 融资，“用学生把土地养肥”。
   - 温6：“失业→没钱消费→更大规模的失业”。
6. **用博弈论讲“个体理性导致集体内卷”。**
   - 温5：“第一个这样做的城市肯定能够成功……所有的城市都学会这个套路之后，这招就无效了。你吸引的人他不是凭空长出来的”。
7. **先质疑自己的数据，用荒谬感检验数字。**
   - 温7：“300户的小区里面，那不得有40户……不但不是瞎说，而且还报的挺保守”；“有没有被人为的调整，我也不能确定”。
8. **给结论加限制条件，落到普通人能用的判断。**
   - 温8：“成本差、供给差、需求差……大盘旺不等于你的生意旺”。
   - 温7：“精神科医生可以做心理咨询，但是心理咨询师不一定能当精神科医生”。

**可迁移**：几乎全部。温义飞的 3–4 分钟单条，正好是“读一条新闻 → 反推 → 正推 → 落到人”的结构。
**不可迁移**：
- 每期末尾升华到地域精神（温1“江西人不屈”、温4“四川人学不会投降”），逻辑断档，听起来像煽情。
- 早期作品的梗（“真香”“祖安人”）。

### 2.3 小Lin说：假设检验型推理，最适合当“深度”的骨架

1. **先列大众解释，承认“有道理”，再指出漏掉的变量。**
   - 林1：“听起来呢确实也都有它的道理。不过我认为……少了一个变量……汇率”。
   - 林8：“简单粗暴版……光让它解释啊，不少会感觉有那么点糙”。
2. **识破同义反复，追问下一层。**
   - 林1：“就是一句废话……因为这个杯子里的水太多了……我们想知道的是为什么这个杯子里的水太多了”。
3. **用反例或对照组证伪。**
   - 林8：“70年代80年代……降息……幅度全都不比86年小……效果也都挺好的……是不是感觉有点问题？”
   - 林1：95 年以后不再干预汇率，逆差反而扩大，“所以很显然不是”。
   - 林8：“美国的互联网泡沫……一两年之后又活蹦乱跳”，反问日本为什么要 30 年。
4. **用预期机制推出“应该怎样”，再拿“可事实呢”反推。**
   - 林1：“按理说哈市场它会自动调节……可事实呢，美国已经持续了近半个世纪”。
   - 林7：“内需也刺激，外需也刺激，数据也不错。那为啥大家体感一般呢？”
5. **用极端思想实验或虚构国家讲清方向。**
   - 林1：“假设美元他要是一夜之间贬值了50%”，以及“奶茶国”。
   - 林6 是现金流链的另一种讲法：每一步都写成谁对谁说了什么。
6. **推出二阶的、反直觉的推论。**
   - 林1：“美国经济越好，贸易逆差越大……硅谷、华尔街……发展的越好，它的制造业……受到压抑”。
   - 林5：“屏幕是打不破了，但是康宁公司的垄断地位被打破了”。
7. **把比率翻成生活语言。**
   - 林6：“兜里的钱连还今年的债都不够”。
   - 林7：“拿到100块钱的补贴，我更倾向于去花出去”。
   - 林7：“电视冰箱洗衣机一用都是十几年”。
8. **在关键处主动降调。**
   - 林5：“小林肯定也没有什么内部消息”。
   - 林8：“是不是真的呢？我也不知道”。
   - 林1：“我敢打赌……我不敢打赌啊，我就那么一说”。
   - 林4：“不一定是最优解”。
9. **讲长链条前先提醒听众，讲完再收一遍。**
   - 林8：“注意啊，要跟住这是一条比较长的逻辑链”，讲完后“咱来总结一下刚刚这个长而又精彩的逻辑链”。
   - 林1：“一点一点要深入到这个问题的核心了”。

**可迁移**：第 1–4、6、7、8 条是本组最值得学的部分。
**不可迁移**：
- “朋友们”式的学姐腔、语气词和猜谜，和不露脸的分析人设不匹配。
- 17–25 分钟的长链条要压缩：4–5 分钟只够“一个大众解释 → 一个反例 → 一个真变量 → 一个二阶推论”。

### 2.4 半佛仙人：换框架、看资金流、激励解释

1. **换掉错误框架。** “你用 A 理解想不通，用 B 理解立刻通”。
   - 佛6：“二房东”换成“非法集资”。
   - 佛5：“车的本质其实就是以一定的速度提供一定的空间”。
2. **不看利润看资金流。** 找时间差。
   - 佛6：“左手尽可能从租客手中一次性收取更多的钱，右手尽可能晚一些把钱给房东”；“看商业本质，不要去算盈亏，要看资金流”。
3. **用激励解释“为什么没人改”。**
   - 佛3：“常规就是他们自己定的……一定是最符合他们利益的选择”。
   - 佛1：“从厂家的视角他没有动力……最有动力破局的人是谁？只会是消费者”。
4. **用单价或成本反推产品设计。**
   - 佛4：维 C 很便宜所以猛加；柠檬酸比苯甲酸便宜，所以用它做防腐和调味。
   - 佛3：主机 299 元，刷头 9.9 元，对照同行刷头 29.9–39.9 元，“他学的是打印机”。
5. **一个起点，多条后果链连推。**
   - 佛2：低价同时推出“供应链 / 用户 / 渠道 / 营销 / 涨价难”五条链，最后合成一句：“没有利润率就没有现货，就没有给渠道商的利润，就没有足够的品宣，就没有能打的产品力”。
6. **找规模经济的反例，指出结构性缺陷。**
   - 佛6：“规模和成本完全无关，甚至反向相关”。
   - 佛2：手机企业“无法凭借主观意志决定自己的产能”，对照传统制造业“工厂说了算”。
7. **把反常的主体行为当信号。**
   - 佛7：“花呗来呼吁大家理性消费，这件事情就很离谱”。
   - 佛2：“黄牛能生存……就代表小米的定价就不合理”。
8. **替对方把道理说完整，再给反驳；也允许自己改口。**
   - 佛3：“以前外国品牌卖那么贵，我是认的……手上的钱不会说谎”。
   - 佛4：“不是商业不允许，是科学和物理不允许”。

**可迁移**：第 1–7 条的推理骨架，尤其第 2、4、6 条，最能让产业链“显形”。
**不可迁移**：
- 粗俗比喻、性暗示、自我介绍梗、“香不香，我就问你香不香”这类重复锤句。
- 商单期（佛1、佛5）缺少反方意见，听起来就是广告。
- 半佛约 400 字每分钟的语速和梗密度，用在我们“申论式拆解”的人设上会显得油滑。

## 3. 可融合进 skill 的推理动作（模板 + 真实例子）

每个动作都按“它解决什么问题 / 模板 / 原例”写。写稿时，一期 4–5 分钟（1300–1600 字）挑 4–6 个动作串成一条链就够了。

**R1 双事实悖论开题（反推的入口）**
- 解决什么：给反推一个起点，让“为什么”有张力。
- 模板：“A 是真的，B 也是真的，但它俩不该同时成立。（给出两个带数字的事实）问题出在哪？”
- 原例：
  - 温5：“增速最快……房价还能这么低？”
  - 温2：“工作难找，大学还在扩招”。
  - 林7：“5.3%看起来非常OK……体感好像不太OK”。

**R2 用比例戳破表象**
- 解决什么：大家以为的主因往往只是小头，要换上真正的大头。
- 模板：“大家以为是 X，但 X 一年只有 a，占总盘子 b 的不到 c%。真正撑起来的是 Y，占了……”
- 原例：
  - 温5：餐饮 500 亿对 GDP 1.3 万亿，工程机械约占全国三分之一。
  - 林1：贸易账户只是“故事的一半”。

**R3 先列大众解释，再指出漏掉的变量**
- 解决什么：最直接的“深度信号”，听众会觉得“原来我只知道一半”。
- 模板：“常见解释有两种：①……②……，听起来都有道理。但它们漏了一个变量：Z。把 Z 放进来，才解释得了为什么偏偏是这里、偏偏是现在。”
- 原例：林1 用汇率补储蓄和赤字的解释；林8 用信用扩张加财团补“降息导致泡沫”的说法。

**R4 用对照组或反例证伪**
- 解决什么：防止单因归因，听起来不像想当然。
- 模板：“如果真是 X 导致的，那么 W（同样有 X 的时期、地方、公司）也该出事。但 W 没事。所以 X 最多是条件，不是原因。”
- 原例：
  - 林8：70、80 年代降息并没有引发泡沫。
  - 林8：别国泡沫“一两年之后又活蹦乱跳”。
  - 林1：95 年以后不再干预汇率，逆差反而扩大。

**R5 机制预期加“可事实呢”**
- 解决什么：从“应该”和“实际”的落差里挖出隐藏的力量。
- 模板：“按 [机制]，本应该 [结果]。可事实呢，[相反的事实] 已经持续了 N 年。所以一定有一股力量在抵消它：……”
- 原例：林1“自动调节……可事实呢……近半个世纪”；巫5“依从性反而高10.5%”。

**R6 逐层追问“为什么是它”（申论的“为何是这个主体”）**
- 解决什么：直接对应我们人设里的“why this unit”。
- 模板：“为什么是 [主体]，而不是 [同级对照]？先看 [定位或定义]：要求是 [一句话]。按这个标准清点：①②③。别人缺 [某项]，它不缺。”
- 原例：
  - 温4：“战略腹地……必须什么都不缺”，并和贵州、云南的定位对比。
  - 巫7：“不同于……制造业，运营商……依赖本地人口规模”。
  - 林4：丰田为什么不照搬福特，因为“一块钢板都恨不得掰两半用”。

**R7 反推到政策节点（申论的“上面是什么政策”）**
- 解决什么：把“现象”接到“上位政策”，产业链就有了起点。
- 模板：“这个变化是从 [某年] 开始的。那一年 [某文件或规则] 改了一条：[原文要点]。改之前 [状态]，改之后 [状态]，在 [指标] 上的表现是 a → b → c。”
- 原例：
  - 温2：2016 年修订民办教育促进法，在校生增量 +12万 → +20万 → +60万 → +80万。
  - 林6：2016 年房住不炒、2020 年三条红线。
  - 林7：政治局会议定调服务消费，随后出消费贷贴息 1%。

**R8 现金流和利益相关方链条（正推，让产业链显形）**
- 解决什么：把“谁做了什么”变成一条钱的路线，每一步都点名一个主体。
- 模板：“钱是这么转的：[主体1] 先 ……，拿着这个去找 [主体2]……，再让 [主体3] 先付一半……最后 [主体4] 的钱进来，正好填上第一步的缺口。”
- 原例：
  - 林6 恒大的政府 → 银行 → 供应商 → 购房者。
  - 佛6 长租的押一付三对月付。
  - 温2 学费 → 补贴 → 土地 → 商圈。

**R9 点名谁买单（附分布）**
- 解决什么：让结论有重量，避免空泛地说“影响很大”。
- 模板：“这件事的成本不会消失，它落在 [群体]。按 [信源]，[低收入或下游] 承担 a%，[高收入或上游] 只有 b%。”
- 原例：
  - 巫3 关税累退，-4% 对 -1.6%。
  - 林6 1.9 万亿里，购房者预缴 2000 多亿、上下游欠款 8600 多亿。
  - 佛6：“年轻人还有未来，所以没有能力跑”。

**R10 用激励解释“为什么没人改、为什么现在改”**
- 解决什么：说明一个机会为什么一直空着，或者为什么偏偏现在被填上。
- 模板：“这个问题不难解决，那为什么之前没人做？因为对 [在位者] 来说，现状正是最符合它利益的安排。真正有动力破局的，只会是 [被损害的一方或外来者]。而现在 [条件变化] 让它第一次做得起来。”
- 原例：
  - 佛3：“常规就是他们自己定的”。
  - 佛1：“最有动力破局的人……只会是消费者”。
  - 温3 预制菜的“为什么是现在”：冷链、监管、工业化。

**R11 二阶推论，结论要反直觉**
- 解决什么：给听众带走一个“想不到”的推论，深度感就靠它。
- 模板：“顺着这个机制再往下推一步：[A 越好]，反而 [B 越差]。所以 [常见政策] 只会 [改变结构] 而不会 [改变总量]。”
- 原例：
  - 林1：“美国经济越好，贸易逆差越大”；对一两国加关税，长期只是让进口结构重构。
  - 温5：“第一个这样做的城市肯定能够成功……都学会之后……无效”。
  - 佛6：“你吃的越多……空房就越能涨价”。

**R12 把比率翻成一句生活语言（专防“念数字”）**
- 解决什么：数字念出来太干，翻成一句人话才进得了耳朵。
- 模板：“[指标] 小于 1，翻译一下就是：……”；“占比 39.1%，就是每花 100 块，有将近 40 块……”
- 原例：
  - 林6：“兜里的钱连还今年的债都不够”。
  - 温8：“每消费100块，有将近40块都来自县乡”。
  - 温5：房价收入比 8.1 对 15.7，就是“合肥人要比长沙人多花一倍的时间才能供完”。
  - 佛4：42 克碳水，“约等于三两米饭”。

**R13 一户人的账（把宏观落到个体）**
- 模板：“具体到一户人：首付 a，贷款 b；价格跌到 c；结果 a 没了，房子没了，还欠 b−c。（这是极端情况）”
- 原例：巫2 的 300 / 700 / 500 / 200；佛6 的“租房成本翻倍”。

**R14 证据分级和主动降调（防 AI 腔、防吹牛）**
- 模板，按信心分三档：
  - 有来源的硬数据：“按 [机构或文件]……”
  - 推断：“我的理解是 / 我倾向于……”
  - 传言：“有一种说法是……我查到它的出处是 [某处]，所以当八卦听，别当论据。”
- 每期至少给一处“我不确定”，以及一处“这只是乐观估计”。
- 原例：
  - 巫2 周刊文春的停车段子。
  - 林8 关于不加息的三个原因：“据不同渠道说……其实是个传言”。
  - 温7：“我也不能确定”。
  - 巫5：“当然这只是乐观估计”。

**R15 预判质疑，先替听众说出来**
- 模板：“你可能会说：‘[最常见的不屑]’。这句话对了一半：[承认部分]。但……”
- 原例：
  - 林3：“你卷这个数字有必要吗？”
  - 佛2：“便宜还有错吗？……当然好，但问题是……”
  - 温8：“为什么看到这种新闻，你总是下意识划走”。
  - 巫4：“当然有人会说……确实如此”。

**R16 给结论加成立条件（收尾，不喊口号）**
- 模板：“所以 [结论] 成立的前提有三个：①②③。缺一个，[结论] 就不成立。”
- 原例：
  - 温8：“成本差、供给差、需求差……大盘旺不等于你的生意旺”。
  - 林1：“it depends”，加心跳类比。
  - 林5：“肯定不是说国产现在就遥遥领先了”。

### 3.1 一期 4–5 分钟的推荐串法（示意）

1. 用 R1 或 R2 开题。
2. 用 R15 预判一个质疑。
3. 用 R3 列出大众解释、指出漏掉的变量，同时接 R7 反推到政策节点。
4. 用 R4 放一个反例或对照组。
5. 用 R8 正推现金流链，配 R12 把数字翻成人话。
6. 用 R9 或 R13 落到“谁买单”或“一户人的账”。
7. 用 R11 给一个二阶推论。
8. 用 R16 讲成立条件收尾，全程穿插 R14 的证据分级。

### 3.2 什么样的句子会显得幼稚或像 AI，原作者又是怎么避开的

| 风险 | 做坏了的样子 | 原作者的处理 |
|---|---|---|
| 空泛的“意义重大” | “这标志着……具有深远意义” | 林3 把“意义”拆成两个机制：成熟材料导致价格战；技术下放的前提是成本可控 |
| 单因归因 | “都是因为广场协议” | 巫2 和林8 都先立靶再证伪；林8 用 70、80 年代的降息做反例 |
| 数字堆砌 | 连念五个百分比 | 每个数字配一个对照分母（巫5 的 20% 对 1%），或翻成一句人话（林6） |
