# 改稿与意见权衡

> 这一节来自一次教训：外部审稿说“反差不成立”，我就把第01、02、03、07期的开头都换掉了，钩子变弱，用户的辨识度也没了。之后另一个 AI 自己撤回了过严的意见。
> 规则：**收到任何新意见（用户的、其他 AI 的、我自己的复查），先分类、再权衡、最后做最小的改动，并把理由记下来。**

## 1. 改稿前，先给原句打标签

每一句被质疑的原句，只能打下面四种标签之一：

| 标签 | 什么时候用 | 怎么改 |
|---|---|---|
| **保留** | 真实、有关、有逻辑；只是写法不合审稿人的口味 | 不动 |
| **补一句或标签** | 原句没错，但容易被误读（主语、口径、新旧、公司说法） | 原句不动，紧跟一句短话（“这个三星不是三星电子”“新旧不同，价差不等于利润”） |
| **待核实** | 数字或说法还没找到出处 | 先查；查不到，换成能核实的同类事实，原句的结构保留 |
| **事实错误须改** | 和原文对不上；范围、对象、口径被悄悄扩大；前后自相矛盾 | 改到和原文一致，改动只限这一处 |

**最小改动**：
- 能补一句解决的，不改原句；能改一个词的，不改整句；能改一句的，不重写一段。
- 改完，用钩子库第 3 节的兑现表检查：钩子还在不在，正文还接不接得住。
- 不要因为一处有错，把整个开头换掉。

## 2. 收到新意见，怎么权衡

**第一步：分类**

| 意见在说 | 例 | 处理 |
|---|---|---|
| **事实错误** | 41.9% 是 A 类股，不是总股本；原奶成本被说成盒装奶成本 | 改。不需要商量 |
| **逻辑断点** | 问“为什么是 2026 年才冒出来”，后文却说 2021 年就开了 | 改，但优先用补一句的方式 |
| **风险提示** | “三星”可能被误解成三星电子；“和华为有关”可能被理解成华为控制小牛 | 补一句标签，不删钩子 |
| **口味偏好** | “开头太花哨”“应该先讲企业名录”“反差必须是真矛盾” | 看它和用户已定的方向冲不冲突；冲突就不采纳，写明理由 |

**第二步：按优先级取舍**（意见之间冲突时，从上往下）：
1. 用户明确说过的方向（人设：从一条新闻顺藤摸瓜；保留自己的钩子；不露脸）；
2. 事实（原文写了什么）；
3. Skill 的硬规则（第 9 节）；
4. 审稿人的口味。

**第三步：问自己三个问题**
- 不改，会不会让观众得到一个**错的**认识？会，才必须改。
- 这个意见是针对**数字比较**的吗？只有数字比较和价值判断才需要同口径；并置和悬念不需要。
- 改了以后，用户原来想要的那个东西（钩子、人设、辨识度）还在吗？不在了，就换一种改法。

**第四步：记录**。在 `交接/外部审稿与修订.md` 里写：意见原文、分类、采纳 / 部分采纳 / 不采纳、理由、改了哪句。

## 3. 已经发生过的过度修改（别再犯）

| 我做过的 | 为什么是过度修改 | 现在的做法 |
|---|---|---|
| 把“所有反差必须过三查”写进 Skill，再用它否掉第01期开头 | 三查只适用于数字比较；“中国车卖得好”和“有人运韩国旧车”是并置，不是计算 | 钩子只过“真、有关、有逻辑”；数字比较才要求同口径 |
| 第02期把价差钩子改成“两张报价单看起来赚翻了，但你仔细看……” | 反差还没立起来就被拆掉，钩子变弱 | 价差先出，口径写进同一句，紧跟一句标签 |
| 第03期判开头是“企业名录课”，没有加用户想要的三星品牌反差 | 品牌反差是好钩子，风险只在主语 | 加回反差，紧跟一句“这是三星 E&A” |
| 第07期删掉整个“骑电摩”开头 | 有问题的只是“印象不太好”这个标签，不是整个开头 | 只删标签，补一句“和华为公司没关系” |
| 8 期结尾全改成二选一决策题 | 互动题是工具，不是每期必须有 | 结尾先回答主问题；互动题可选 |

**保留没回改的**（这些是事实错误，改对了）：
- 第04期：原奶成本 ≠ 盒装奶成本；大豆进口依赖 ≠ 全部饲料蛋白进口依赖；
- 第06期：“只对了三分之一”（原因个数不能换算成贡献比例）；“3 到 6 个月就能交”（不同等级的产品不可比）；
- 第07期：41.9% 是 A 类股；
- 第08期：半年数据不说“同期”；天津中南、海南中南是“张氏家族间接拥有 70%”，不是全资；公司原话是“垂直整合原料优势”。
