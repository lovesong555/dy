# 选题方法：出口追链（账号主线，固定这样找）

> 2026-10-25 用户定：人物类试水效果不明显，因为和人设不符。主线回到“从一条资讯拆出一门生意”。样板是烟台 / 蓬莱港区那几期：一条港口新闻 → 知道货是谁的 → 知道它在当地卖多少钱、做什么项目 → 拼出这家企业在当地的整体布局。

## 一、什么算“合格”的选题（七条都要有）

1. **起点是一条官方稿**：海关、边检、口岸、港口、贸促会、商务部门发的。稿里有具体货物（最好有型号、批次、数量、货值），有航线 / 口岸 / 目的国。
2. **查得出货主**：哪家企业生产或承运，要有企业侧的证据（公告、官网新闻、招投标结果、当地媒体）。
3. **查得到目的地**：当地的项目、工厂、合同金额，或者当地的挂牌价、售价。
4. **拼得出布局**：这家企业在当地的工厂、子公司、合同、合作方。
5. **说得出“为什么是现在”**：政策、关税、项目节点、竞争对手的变化。
6. **有信息差**：普通人看新闻只看到“出口增长了”，拆完能看到一条具体的生意。
7. **撑得起 1000–2000 字**：A / B 级证据（官网原文、公告、合同）不少于 5 条。

缺第 2 条（查不出货主）的，直接放弃。

## 二、去哪找（信源地图）

| 层 | 信源 | 能给什么 |
|---|---|---|
| 起点 | 海关总署及各直属海关官网、公众号（“XX 海关助力……首批出口”） | 货物、数量、货值、目的国，常常点名企业 |
| 起点 | 港口集团官网、公众号（滚装、件杂货、新航线、大件出运） | 船名、航线、货种、件数 |
| 起点 | 陆路口岸、班列运营方、国铁各局（中欧 / 中亚班列、中老铁路、陆海新通道） | 班列货品、首发、目的站 |
| 起点 | 边检站（国家移民管理局、各边检站） | 外籍船舶、特殊运输、大件通关 |
| 起点 | 贸促会（原产地证）、商务部门（“走出去”项目）、中信保（承保项目） | 企业、目的国、项目类型 |
| 货主 | 巨潮资讯、港交所披露易、企业官网新闻、招投标网站 | 合同金额、工厂、海外子公司 |
| 目的地 | 目的国政府、业主官网、当地媒体、当地二手 / 新品挂牌网站 | 项目进度、当地售价 |
| 为什么是现在 | 政策原文、关税公告、行业协会数据 | 时间节点 |

## 三、怎么分工（多个助手同时找）

按“地区 + 信源类型”分 4–5 路，每一路都从找起点一直追到货主和布局，不拆成“有人只找起点、有人只追货主”（那样对不上）：
- 华南海关和港口；
- 华东和长江沿线的海关和港口；
- 陆路口岸、班列和边检；
- 华北、东北的海关和港口；
- 从企业侧反查：先找上市公司的“首批出口”公告，再回头找能对上的官方稿。

每一路：先广撒网找 15 条以上候选 → 挑 4–5 条深挖 → 留 3–4 条最好的；结果写进文件，回复里只报标题和自评分（省 token）。最后由主控汇总、交叉核实、去重，选出最终的题。

## 三之一、拆的对象可以放宽（2026-10-25 补充）

不一定落到某一家企业，下面这些都可以拆，前提是起点仍然是一条具体的近期新闻：
- **一个行业**：谁出钱、谁出力、钱怎么分。
- **一种商业构思或商业架构**：订阅、加盟、平台抽成、授权、中间商。
- **外国的行业经验**：参考彭博、日经、路透等外媒，比如日本的艺人经济（偶像事务所）、综合商社、便利店加盟、动漫制作委员会，韩国娱乐公司的练习生体系。拆清它怎么形成、今天有什么变化，再和中国对照。

另派一路助手专门找这类题，不和出口追链混在一起。

## 四、避免撞题

已经做过的题不再做：
- 烟台 / 蓬莱港区：二手车去中亚、挖掘机去圭亚那（紫金矿业）、现代冰轮锅炉去阿联酋；
- 蒙牛巴西大豆、悉尼地铁、美国变压器、小牛电动、玖龙纸业。

山东港口暂时不再选。

## 五、2026-10-26 修订：先过“看得见”这一关（来自 10 位博主研究）

> 依据：`研究记录/博主学习/选题研究_2026-10/总结_怎么学成.md`。

上一批 10 条，用户一条都不满意。原因是起点写的是“XX 企业出口 XX”：观众看不见，也没为它付过钱，开头说完企业和目的地，结尾就被猜到了。

10 位博主的高播放选题都是同一个公式：
> **观众看得见、或者付过钱的东西 × 一个反常点 × 钱（或权利、风险）最后去了谁那里**

**宋玉的三个选题公式**：
1. 【看得见的东西】为什么【反常】？（例：造变压器的和造卡车的，为什么挤在同一条船上去坦桑尼亚？）
2. 【A 发生了】，为什么【看似无关的 B】先【涨 / 赚 / 死】？（例：霍尔木兹一出事，广西的液氨卖到了印度）
3. 【观众付过钱的东西】，钱最后到了谁手里？（例：动画卖爆了，画动画的能分到钱吗？）

**选题自检（四条都要过）**：
1. 不懂行的人看标题，能说出“我见过 / 我买过 / 我听说过”；
2. 30 秒内有一个真实数字；
3. 有一份别人懒得翻的原件（标书、裁定、财报附注、外国政府调查）；
4. 最后能画出“钱、权利、风险去向图”。

**固定视角**：每期结尾都交付一张“去向图”（谁出钱 → 经过谁 → 谁拿走 → 风险留给谁）。

**叙事骨架**（4–5 分钟）：物件钩子 → 通常解释 → 解释不了的事实 → 原件 / 账 → 对照 / 排除 → 谁买单 + 去向图 → 回扣开头。

**给用户出题的方式**：一次给 3 条，让用户挑；挑定后再补齐待核的证据、写稿。
