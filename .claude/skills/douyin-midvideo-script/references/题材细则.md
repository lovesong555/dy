# 题材细则：人物 / 事件 / 政策 / 宣传稿

> SKILL.md 第 5 节是总表。这里按起点分开写细则，写哪一类就只读哪一节。
> 四类共用同一套方法：宽查窄讲、主问题卡、段落公式、“但是 / 所以”。不同的只是**从哪下手、主链长什么样、哪里最容易出错**。

---

## A. 人物（今昔反差、创始人、决策者）

**适用**：起点是一个人（一张照片、一句话、一个头衔、一份持股表）。

**主问题一般是“关系”或“选择”**：他和这门生意现在是什么关系？他当年为什么这么选？

**主链**：
1. 他当年是谁（≤30 秒，只留和主问题有关的一两件事）；
2. **但是**一个转折（离职、出事、转行、公告里的一个变化）；
3. **所以**他现在和这门生意的真实关系，**四种权利分开说**：
   - 持股（直接 / 间接，多少，哪类股）；
   - 受益（信托受益人、家族持股）；
   - 投票（A / B 类股的投票权安排）；
   - 管理（是不是董事、高管，管不管经营）；
4. 这层关系意味着什么（谁决策、谁出钱、谁承担后果）。

**钩子**：熟人 → 陌生的链（钩子库第 3 类）。例：骑电摩的年轻人 → 小牛 → 李一男。
- 紧跟一句说清**和谁有关、和谁无关**（“和华为公司没关系，关系在这个人身上”）。
- 不给任何群体贴标签（“印象不好”）。

**必须有的证据**：旧刊原文（人物当年的身份）；现在的披露文件（年报、20-F、13D、港交所权益披露）。

**常见坑**：
- 写成履历，2 分钟都在讲过去；
- 股份口径混用：A 类股 ≠ 总股本，持股 ≠ 投票权；
- “不在高管名单”被说成“不参与经营”；
- 坊间数字（收购价、身家）当事实。没被证实的，口播里说“没有被证实”。

**画面**：人物插画只在两处出现：第一次介绍；讲到他出钱或拍板的那一刻（人物 → 资金 → 公司）。其余时候不出现（SKILL 第 9 节第 8 条）。

## B. 产业链事件（一船货、一个订单、一条航线、一台设备）

**适用**：起点是一条港口、海关、企业通稿，一张照片，一份合同。

**主问题一般是“原因”或“机制”**：为什么走这条路？为什么在这里造？这笔钱买了什么？

**主链**：
1. 起点细节（照片上的一个 logo、通稿里的一个词）；
2. 货从哪来、到哪去（每一站点名主体）；
3. 为什么是这里、为什么是现在（条件、政策节点、替代路线为什么不行）；
4. 谁在赚什么钱（每一层点名主体、给出数字）；
5. 缺的一环（公开资料对不上的部分，明说）。

**钩子**：具体场景 / 品牌反差 / 大势和例外的并置（钩子库第 3、6 类）。
- 并置不需要是矛盾。
- 主语要说对（三星 E&A ≠ 三星电子）。

**常见坑**：
- **“新”的到底是什么没说清**：是新通道、新货种，还是新运法（第01期：通道 2021 年就有，新的是铁路笼车运二手车）；
- 国家和市场来回切，一次讲好几个国家；
- 时间上的吻合说成因果（“节奏严丝合缝”可以说，“因为”要有原文）；
- 用公司介绍代替主链（四个 logo 按出场顺序讲，而不是按“谁要建 → 谁总包 → 谁分包 → 谁来造”的任务链讲）。

## C. 政策（禁令、补贴、标准、规划）

**适用**：起点是一份政策原文，或者一条“某某新规”的新闻。

**主问题一般是“影响”或“选择”**：这条政策卡住了谁？被卡住的人有几条路，选了哪条？

**主链**：
1. 政策原文要点（**原文截图**，只截一段，荧光笔高亮，带文号和日期）；
2. **所以**它卡住了谁（具体的企业或行业，不是“相关企业”）；
3. **所以**被卡住的主体有几条路，每条路的约束是什么（有几条列几条，不固定数量）；
4. 谁选了什么、付了什么代价（财报、公告里的数字）。

**钩子**：从一个受影响的具体主体开题，而不是从政策本身开题（第08期：从港交所公告里的“木片”两个字开题，政策在第二环才出现）。

**常见坑**：
- 只讲政策本身，变成科普；
- 把“相关”说成“导致”：政策出台后数据变了，不等于是政策导致的；
- 原文的范围被扩大（“禁止进口固体废物”≠“禁止一切进口原料”）。

**证据**：政策原文（政府官网截图，法律法规和官方文件不受著作权保护）；执行前后的数据；受影响主体的公告。

## D. 宣传稿（企业通稿、政府通稿、业绩新闻）

**适用**：起点是一篇报喜的稿子。

**主问题一般是“真相”或“机制”**：这篇稿子真正有信息量的是哪一句？它没说什么？

**主链**：
1. 通稿说了什么（一句话概括，标明“公司说法 / 官方说法”）；
2. 原文里**真正有信息量的那一句**（一个数字、一个新词、一个名单变化）；
3. 拿其他公开数据对照（年报、海关数据、行业协会数据）；
4. 通稿没说的部分（利润、成本、风险、对手）。

**钩子**：名人一句话 → 验证（钩子库第 4 类）；或者通稿里一个反常的词。

**常见坑**：
- 把宣传口径当事实，没写“这是公司的说法”；
- 公司的业绩归因（“主要得益于……”）当成已证明的原因；
- 为了显得犀利，把通稿说成“骗人”。对照数据说明到哪一步就说到哪一步。

---

## E. 价格反差（同一东西两地价）

**主问题**：先“真相”（这两个价格能不能比），再“原因”（真正的需求从哪来，价格里有哪几层）。

**钩子**：价差先出，口径写进同一句，紧跟一句标签（钩子库第 2 类和第 0 节）。

**常见坑**：新旧、年份、配置不同还硬比；“价差”说成“利润”；用户口头说的数字（例：40 万）没有报价单就进口播。
