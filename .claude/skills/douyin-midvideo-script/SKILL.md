## 0. 人设和总原则：宽查窄讲

**人设**：一个只看公开资料的人（新闻、公告、年报、政府文件、公众号），从一条不起眼的新闻出发，顺藤摸瓜，把谁做了什么、钱和货怎么走、为什么是现在、谁承担后果，一层层拼出来。观众会觉得这人像在现场待过，但他从来不说“我在现场”。

**人设怎么体现**，不靠多讲几条线，靠三件事：
1. **证据的厚度**：每个关键判断，画面上都有原文。观众看得出背后翻过很多份文件。
2. **链条的完整**：从新闻里的一个细节，一路追到源头和后果，中间不跳步。
3. **克制**：能确定的说死，不能确定的明说“公开资料没有”。高手的可信度来自知道边界在哪。

**宽查窄讲**（这一条同时回答“人设要广”和“审稿要窄”）：
- **查要宽**：围绕新闻，把相关主体、政策、数据、历史都查一遍，建一个“证据库”，查到的东西越多越好。
- **讲要窄**：一期只回答**一个主问题**，口播只走**一条主链**。产业链上的每一环必须是这个问题答案的一部分。和主问题无关的发现，哪怕再精彩，也只进证据库，或者留作下期选题。
- 判断某个材料该不该进口播：**拿掉它，主问题的答案会不会断？**断，就留；不断，就移出。

## 1. 工作流（按顺序，每步有产出物）

| 步 | 做什么 | 产出物 |
|---|---|---|
| ① 起点 | 选一条新闻、公告、人物或宣传稿，找出里面**一个具体的细节**（一个数字、一个词、一张照片、一句原话） | 起点卡：细节 + 出处 |
| ② 宽查 | 用申论要素拆解每条信源（第 3 节），顺藤摸瓜，查主体、钱、货、政策、历史 | 证据库（表格：事实 / 出处 / 日期 / 口径 / 等级） |
| ③ 定题 | 从证据库里选出**一个主问题**，写出**一句话直接答案** | 主问题卡（第 2 节） |
| ④ 搭链 | 用金字塔原理，把答案拆成 3–4 个环节，每环配上关键证据 | 主链表（第 4 节） |
| ⑤ 写稿 | 按段落公式写，段与段之间用“但是 / 所以”衔接 | 口播稿 |
| ⑥ 顺稿 | 按第 7 节逐条过一遍，朗读一遍 | 改后稿 |
| ⑦ 自检 | 按第 10 节的清单打勾 | 自检表 |
| ⑧ 分镜 | 全时间线表：每句口播对应一个画面来源 | `scenes/<期>.json` |
| ⑨ 试制 | 先做 60–90 秒完整段（配音、字幕、证据、动画），抽帧审、按手机尺寸审 | 试制片 + 验收记录 |

**不要跳步**。特别是：没有主问题卡，就不写稿；没有通过自检，就不做分镜；试制段没验收，就不批量做。

## 2. 定题：一个主问题 + 一句直接答案

### 2.1 主问题卡（必须写全，写不出来就回去查）

```
起点细节：（例：2026-05-18 港交所公告里，家族公司的供货清单第一次出现“木片”）
主问题：（一句话，观众能听懂）
问题类型：原因 / 选择 / 机制 / 影响 / 关系 / 真相（见 2.2）
直接答案：（一句话。答不出来，说明证据不够）
关键证据：（真正改变理解的那一两份文件。可以多份共同证明，不要求只有一份）
缺的一环：（公开资料证明不了的部分，口播里要明说）
人设钩子：（这条新闻里，普通人会忽略、而“高手”一眼看出的那个点）
```

### 2.2 按问法取材（借申论“按问法答题”）

题型决定你去证据库里拿什么。**不跨维度**：问原因，就不要把成效当原因讲。

| 主问题类型 | 例 | 去证据库里找什么 | 主链的样子 |
|---|---|---|---|
| **原因**：为什么会这样 | 韩国旧车为什么经过中国 | 主观做法 + 客观条件；政策节点；替代方案为什么不行 | 现象 → 条件 1 → 条件 2 → 为什么是现在 |
| **选择**：为什么选 A 不选 B | 玖龙为什么加码自建浆 | 可选的几条路及各自约束；选择后的投入和代价 | 原来的路 → 路断了 → 几条路 → 选了哪条、代价是什么 |
| **机制**：这东西怎么运作 | 39.6 亿合同到底买了什么 | 合同、条款、分工、钱的流向 | 拆开 → 各部分 → 谁负责什么 → 哪些没公开 |
| **影响**：会带来什么 | 禁废令对纸厂意味着什么 | 前后数据；谁受益、谁承担 | 变化 → 一级影响 → 二级影响 → 谁买单 |
| **关系**：A 和 B 什么关系 | 李一男和小牛现在什么关系 | 持股、受益权、投票权、管理权分别是谁 | 表面关系 → 逐层拆权利 → 实际关系 |
| **真相**：说法对不对 | 39.6 亿 ÷ 16 是单价吗 | 原文口径；说法的出处 | 流行说法 → 原文 → 差在哪 → 正确理解 |

### 2.3 开头的钩子：真、有关、有逻辑

钩子是入口，不是结论。只过三关（细则和例子见 `references/钩子库.md`）：
1. **真**：每个事实有出处。
2. **有关**：正文会兑现它（写完填兑现表）。
3. **有逻辑**：两件事放在一起，能引出一个可以追下去的问题。**不要求是矛盾**。

**同口径只管数字**：钩子里有数字计算或价值判断（贵、便宜、翻倍、赚、亏）时，口径写进同一句，紧跟一句短标签；年份对不上，不写“同期”；两件事能同时成立，不说“说不通”。
**并置不用过三查**：宏观和个案、身份和生意、品牌和产品、大势和例外，都可以直接用，只要主语说对。
**用户给的钩子，默认保留**，按 `references/改稿与意见权衡.md` 打标签、最小改动。

## 3. 宽查：申论式信源拆解

### 3.1 每条信源先拆要素（归纳概括）

| 要素 | 问 |
|---|---|
| 主体 | 谁？（具体到公司、部门、个人，不写“企业”“政府”这种泛称） |
| 做法 | 做了什么？（动词 + 对象） |
| 成效 / 影响 | 带来了什么？（对象 + 变化，带数字） |
| 背景 / 问题 | 为什么要做？原来卡在哪？ |

### 3.2 再问三层（综合分析）

1. **和什么有关？替谁解决了什么问题？**（链上的上下游）
2. **为什么需要？**（原来的问题，数字化）
3. **为什么是这个主体？上面是什么政策？**（政策写到文号或公告编号）

### 3.3 证据分三种“成立”

| 成立什么 | 例 | 怎么证明 |
|---|---|---|
| **事实成立** | 玖龙重庆化学浆 2026 年 9 月投产 | 原文（公告、文件、报道） |
| **解释成立** | 它为什么选择自建 | 多份证据加推理；排除其他解释；说明缺的一环 |
| **表达成立** | 观众能跟着这条解释走 | 第 7 节顺稿 + 第 9 节试制验收 |

**前一项通过，不代表后两项通过。**事实全对的稿子，解释也可能不成立，观众也可能听不懂。

### 3.4 证据等级（口播里要说出来）

- **A 原文**：政府文件、交易所公告、年报、法院文书 → “公告写明……”
- **B 媒体报道或第三方统计** → “据某报道 / 某机构统计……”（只有一个来源时，要说“据某报道援引”）
- **C 推断** → “从产能表看，可能是……这是一种解释”
- **D 行业线索或传言**（包括用户提供的行业信息）→ 可以当研究起点；公开表达时标“行业信息，未公开证实”，或者不说。

### 3.5 材料取舍（同组合并 + 旁枝出库）

- **同组合并**：同一主体、同一维度的几条材料合成一条讲，不要分三次讲。
- **一次只换一个对象**：讲完一个国家、一家公司，再换下一个，不要来回切。
- **旁枝出库**：和主问题无关的材料，再精彩也移到证据库的“下期选题”栏。

## 4. 搭链：金字塔原理 + 链条完整

### 4.1 结构（结论先行、以上统下、归类分组、逻辑递进）

```
主问题 → 直接答案（全片的结论，开头 30 秒内要让观众知道在追什么）
  ├ 环节 1：（一个分论点 = 答案的第一部分）—— 关键证据
  ├ 环节 2：……—— 关键证据
  ├ 环节 3：……—— 关键证据
  └（可选）缺的一环：公开资料证明不了的部分
```

- **环节要递进**（前一环推出后一环），或者**互不重叠、合起来完整**（MECE）。
- **每一环只回答一个子问题**。
- **章节条写成“一条链的三步”**，例如“链怎么搭起来 → 路断了有几条 → 选了哪条、付了什么”，不写成三个并列问题。

### 4.2 产业链的完整，不等于讲全产业链

人设要求“完整产业链”，意思是**和主问题有关的那条链从头到尾不断**：源头在哪，经过谁，到谁手里，钱怎么回来。不是把上下游每个行业都介绍一遍。
每一环都要说清：**谁 → 做了什么 → 凭什么拿这一份 / 为什么是它**。

### 4.3 链里的主语不能悄悄变

- 一期里有两个主体（例：张茵家族公司 vs 上市公司玖龙），每次切换都要明说。
- 两件事之间的关系，要标清楚是“证据证明”还是“我的分析”。
- 例：家族公司新增“木片”供货，和玖龙自建木浆线，是**两个主体的两项变化**。要补上：木片是做什么用的 → 谁买、谁加工 → 和自建浆线有什么联系 → 哪部分有证据、哪部分是分析。

## 5. 题材配方（同一套方法，四种起点）

| 起点 | 主问题通常是 | 主链 | 必须有的证据 | 常见坑 |
|---|---|---|---|---|
| **产业链事件**（一船货、一个订单、一条航线） | 原因 / 机制 | 货从哪来 → 为什么走这条路 → 谁在赚什么钱 → 为什么是现在 | 港口、海关、公告、合同原文 | 国家和市场来回切；“新”的到底是什么没说清（是新航线、新货种，还是新组织方式） |
| **政策**（禁令、补贴、标准） | 影响 / 选择 | 政策原文要点 → 卡住了谁 → 受影响的主体有几条路 → 谁选了什么、付了什么 | **政策原文截图**；执行前后的数据 | 只讲政策本身，变成科普；把“相关”当“导致” |
| **人物经历**（今昔反差） | 关系 / 选择 | 他当年是谁（≤30 秒）→ 一个转折 → **他现在和这门生意的真实关系**（持股、受益、投票、管理分开说）→ 这层关系意味着什么 | 旧刊原文；现在的公告、披露文件 | 写成履历；人物和产业链脱节；股份口径混用（A 类股 ≠ 总股本）；“不在高管名单”≠“不参与经营” |
| **宣传稿**（企业、政府通稿） | 真相 / 机制 | 通稿说了什么 → 原文里真正有信息量的那句 → 和其他公开数据对照 → 通稿没说的部分 | 通稿原文 + 对照用的原文 | 把宣传口径当事实；没写清“这是公司说法” |
| **价格反差**（同一东西两地价） | 真相 → 原因 | 两个价格为什么不可比（或可比）→ 真正的需求从哪来 → 价格里有哪几层 | 同口径报价；运费、税、售后的原文 | 新旧、年份不同还硬比 |

## 6. 写稿：段落公式和开头结尾

### 6.1 每段的公式（借申论的分论点段）

```
段首句：这一环的结论（一句，观众一听就知道这段讲什么）
证据：1–2 个，带出处和口径（画面上放原文）
解释：证据为什么支持这个结论（替当事人算账、点名主体）
回扣 / 过渡：这一环回答了主问题的哪部分 + 用“但是 / 所以”推出下一环
```

### 6.2 开头（0–30 秒）

1. 起点细节：一个具体的词、数字或画面，带出处。
2. 人设钩子：普通人看到的是什么，而这里藏着什么。
3. 主问题：一句话问出来。
4. （可选）预告主链的三步。

**不强制**：前三秒必须出数字；必须说“你第一反应肯定是……错”；必须“三个问题”。这些都是可选工具，用之前想清楚适不适合本期。

### 6.3 结尾（最后 30 秒）

1. 回到主问题，给出直接答案。
2. 结论成立的条件，或者缺的那一环。
3. （可选）一个观众能接住的问题。**不是每期都必须有二选一**。有的话，要问刚讲清楚的取舍，不问需要预测能力的宏观问题，不出假二选一。

**不要**：上价值、喊口号；扩大结论（例：把“原奶成本”说成“盒装奶成本”）；用“下次有人跟你说……”去重复一个正文没证明的结论。

## 7. 顺稿：让口播听起来是一条线

**7.1 “但是 / 所以”规则**（源自美剧《南方公园》编剧总结的叙事规则，也就是 And-But-Therefore）：
- 段与段之间，只能用“**但是**”（推进到下一个矛盾）或“**所以**”（推出后果）连接。
- 如果两段之间只能用“**然后 / 还有 / 另外 / 第二个问题来了**”连起来，说明它们是并列罗列，不是一条链。这时要合并，或者把其中一段移出。
- 朗读时在每个段落交界处问自己：这里能说“所以”或“但是”吗？

**7.2 主语一致**：每段开头说清主语。主语一变（家族公司 → 上市公司；美国 → 中国），就要明说。

**7.3 旧信息带新信息**：每句话从观众已经知道的东西说起，再引出新东西（“刚才那份公告里……”“这条链的前提是……”）。

**7.4 一次只换一个东西**：一句话里不同时换对象、换年份、换口径。

**7.5 数字**：一句话最多一个关键数字。比率要翻成人话（“每 10 包里有 8 包”）。

**7.6 听感**：
- 句子短，单句不超过 25 字为宜。
- 少用书面连接词（“与此同时”“综上所述”）。
- 自己读一遍，卡住的地方就改。

**7.7 删的顺序**：超字数时，先删旁枝，再删修饰，最后才动证据。

## 9. 硬规则（违反任何一条都要重写）

1. **身份**：不写“我在现场 / 我看到 / 我拍到”；只写“公开资料 / 公告显示”。
2. **可比性**：数字比较和价值判断（贵、便宜、翻倍、赚、亏）要同口径、同期，对不齐就在同一句里标明（2.3）。并置和悬念不需要过这一条。
3. **因果克制**：
   - 不写“只剩一条路”“唯一”“必然”，除非已经逐一排除，并且说出了依据。
   - 原因的“数量”不能换算成“贡献比例”（列了三个原因，不等于 AI 只占三分之一）。
4. **证据边界前后一致**：中段说“公开资料没对上”，结尾就不能当成已证明。
5. **不扩大结论**：范围（原奶 ≠ 盒装奶）、对象（饲料蛋白 ≠ 大豆）、口径（A 类股 ≠ 总股本）都不能悄悄换。
6. **公司说法要标明**：宣传稿、业绩归因写成“公司说法”，引原话。
7. **图形和被度量的东西同类**：纸浆用纸浆包，奶价用奶桶，钱用钱流；占比写进主标题；半年数据不和全年并排。
8. **人物出场**：只在观众需要知道“谁决策、谁出钱、谁承担后果”时出现。拿掉头像信息不受影响，就删掉。
9. **原文截图**：
   - 法规、公告、旧报道的关键句，放官网或交易所原文截图，只截一段，荧光笔高亮。
   - 截完要读原文（原文常能纠错）。
   - PDF 用 PyMuPDF 渲染。
10. **版权**：
    - 字体只用思源黑体 / 思源宋体（SIL OFL）。
    - 图标原创。
    - 照片用公有领域或 CC，并署名。
    - 人物插画是演绎作品，要标注出处，并说明风险。
11. **手机优先**：
    - 竖屏原生排版，底部留字幕区；
    - 标题一行不超过 12 个字；
    - 公告只放一段。
12. **版本一致**：口播、字幕、配音、画面必须是同一版本（改了口播，就重新生成配音和字幕，见 `交接/试制段流程/make_segment.py`）。
13. **改稿最小化**：用户的原句先打标签（保留 / 补一句或标签 / 待核实 / 事实错误须改），能补一句就不改原句，能改一句就不重写一段。收到任何意见，先分类、权衡，再动手（`references/改稿与意见权衡.md`）。
14. **配音前查多音字**（用户在第07期听出“同行”被读成 tóngxíng）：
    - 先列出稿子里的多音字词，重点看：行（同行、行业、银行）、长、重、还、只（一只）、少（少年）、当、数、得、地、着、了、为、中、发、场、便、差、传、调、量。
    - 机器配音读错风险高的，**换一个不歧义的词**：同行 → 竞争对手 / 其他品牌；一只信托 → 一个信托；少年班 → 换说法。
    - 数字编号要按位读：18650 读“一八六五零”。在 chunks 里加 `tts` 字段写读音，字幕仍显示原文（`make_segment.py` 已支持）。
    - 配音生成后，把成片从头听一遍再交付。
15. **真实素材优先**：
    - 自己画的动画只用来讲关系和数字。
    - 能用真实视频、照片、网页的地方就用（发布会视频、官方账号视频、新闻配图、交易所文件），每一个都在画面上写出处：谁发的、哪天、哪个平台。
    - 镜头类型：`clip`（视频片段，先用 ffmpeg 抽成帧序列，因为无头浏览器解不了 H.264）、`photo`（照片）、`proof`（网页 / 文件截图）。
16. **网页截图静止展示**：`proof` 默认 `zoom:0`、`still:1`，只用荧光笔标出关键句，不推近、不晃动。

## 11.1 出片流程（省 token、省时间，固定这样做）

一条命令出片：
```
python3 交接/试制段流程/make_video.py <分镜.json> <输出目录> <成片名>   # 默认只出竖版
```
它会依次：读音检查 → 配音（文字没变就复用）→ 分镜 → **只重渲改过的镜头**（按镜头算指纹）→ 分两路并行渲染（本地网页服务没开会自动开） → 合成 → 出一张审片小样。

改稿时按这个顺序，不要整片重来：
1. **先定稿再出片**：口播、镜头顺序在 JSON 里改好，并让读音检查通过。
2. **先看静帧，再出视频**：新镜头类型或新版式，先每个镜头截 1 张静帧拼成一张图看；没问题再渲染视频。
3. **只改哪句、重做哪句**：改一句口播只会重配这一句、重渲这一个镜头；改引擎（`scene.html`）才会全部重渲。
4. **审片只看一张图**：看 `审片_竖版.jpg`（每 2 秒一帧拼成一张），不要一帧一帧读。
5. **配音核对**：成片配音用语音识别转文字，和稿子逐字比对，只看有差异的地方。
6. **长任务放后台**：渲染用 `make_video.py`，它自己管等待；不要写 `pgrep` 轮询（会匹配到自己，一直卡住）。
7. **少读大文件**：命令输出只看最后几行摘要；查东西用 grep，不整篇读。
