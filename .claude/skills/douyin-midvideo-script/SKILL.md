# 抖音中视频文案 Skill（产业链 / 财经解读类）

本 Skill 从四篇样本口播（巫师财经《AI风口与你无关》《伊朗局势对资本及我国的影响》《劳动是世间万物的本源》，以及《HYROX 背后的商业与资本游戏》）中提炼。
目标：3–5 分钟、1100–1600 字、每 20–30 秒一个“再钩子”，所有数字可点开出处。

---

## 一、样本博主的叙事骨架（拆解结论）

| 样本 | 开头 15 秒在做什么 | 中段推进方式 | 结尾 |
|---|---|---|---|
| AI 风口与你无关 | **立靶子**：“大量媒体谈 AI 风口，一个视频秒杀他们——四个大字：与你无关”。随后**模仿对方话术**（“你们那个年代机会那么多……你是不是废物呀？”换个版本再说一遍） | “放屁”→ **追问钱流**：算力在谁手里？平台谁建的？利润流向谁？→ **类比**（微信从风口变成自来水）| 给观众可执行建议 + **社交货币**（“谁让你焦虑，就用这个视频回他”） |
| 伊朗局势 | “讨论同质化太严重了，我们**换个角度**：纯资本利益层面” + **一个即时数字**（原油一柱擎天，霍尔木兹 30%） | **先承认大众观点再拆穿**（“油价涨物价就涨？别听他们扯淡”）→ **自己做的图** + 逐句解释横轴纵轴（R²=0.50 vs 0.057）→ **生活化换算**（5 块钱薯片运费只占几分钱）→ **给一个可自查的指标**（战略石油储备）→ **意外角度**（比亚迪挨导弹）→ **极端数字**（里亚尔贬值两万倍） | 情绪升华（“打得一拳开，免得百拳来”）+ 饭桌装X 社交货币 + 关注 |
| 劳动是本源 | 接续上期金句（“债务不是手段，债务就是目的”） | **第一性原理** + **自创概念词**（“毛”“萝卜”“主神视角”）+ **游戏类比**（蓝量、查克拉） | 抛出“没有阴谋，只是一场无意识的市场化运动”的反转 |
| HYROX | **热点事件**（北京站出圈）+ “更有意思的是**背后的商业和资本游戏**” | **算账**（报名费、门票、摄影费、周边、授权）→ **起源故事**（2017 年德国人创办）→ **对比**（马拉松不属于任何公司，HYROX 的 IP 属于公司）→ **悬念揭晓**（“背后股东你猜是谁？万达王健林，没想到吧”）→ 护城河分析 → 本土化打法 → 雪球 → LVMH 接盘 | **反讽收尾**（“老王这波是运气好呢，还是运气好呢”） |

**共同规律（必须遵守）：**
1. **开头不讲背景，先给冲突。** 一个数字反差 / 一个身份反差 / 一个大众误读，三选一，15 秒内说完。
2. **立一个靶子。** “很多人以为… / 媒体都在说… / 你第一反应肯定是…”，然后用证据打掉它。观众爱看“纠正”。
3. **承诺独家视角。** “今天换个角度”“这些别的视频不会给你算”。但承诺必须兑现：必须有一张自己做的图或一笔自己算的账。
4. **追钱流，而不是讲新闻。** 每期都要回答：钱从谁口袋出来？经过谁？最后落在谁手里？谁承担风险？
5. **每 20–30 秒一个再钩子**：设问（“你猜是谁？”）、悬念（“这还没完”）、反转（“但问题来了”）、数字落差。
6. **用生活化单位换算大数字**：“相当于…”“摊到每…只有…”。
7. **图表要“讲”出来**：“这张图横轴是…纵轴是…你看这条线…”，让图成为证据而不是装饰。
8. **结尾给社交货币**：一句能在饭桌上复述的结论 + 一个反问或反讽，引导评论。

## 二、本账号的写作规范（在样本基础上的“安全改良版”）

- **人设**：“港口边上看产业链的人”——用户本人在山东烟台/蓬莱一线拍到真实设备与货物，这是别人没有的**现场证据**，每期尽量让一个现场画面出现在前 30 秒。
- **语气**：口语、短句、可以有“你看”“说白了”“这还没完”，**不用粗口**，不做人身攻击（样本中的粗口与“放屁”会影响推流和品牌合作）。
- **事实分级**：口播中【确定】的数字直接说；【推算】的必须说“按…口径估算”；【待确认】的不进口播。
- **禁止**：把总包金额除以数量当单价；把挂牌价当成交价；把相关性说成因果；拿其他批次/其他年份画面冒充本事件（必须打“资料画面/示意”）。

## 三、4–5 分钟结构模板（约 1300 字 ≈ 4 分 20 秒，按 300 字/分钟计）

| 段落 | 时长 | 字数 | 任务 | 常用句式 |
|---|---|---|---|---|
| ① 钩子 | 0:00–0:15 | 60–80 | 一个反差 + 一个问题 | “X 是 A，但 Y 却是 B。为什么？” |
| ② 立靶 + 承诺 | 0:15–0:40 | 100–120 | 说出大众第一反应，宣布要拆穿 | “你第一反应肯定是…。错。今天把这笔账拆给你看。” |
| ③ 事实锚点 | 0:40–1:20 | 180–220 | 2–3 个硬数字，带出处画面 | “先看官方数据…” |
| ④ 机制拆解（主体） | 1:20–3:10 | 450–550 | 钱流/货流/产业链，2–3 个小反转 | “这还没完…”“问题来了…”“你猜是谁？” |
| ⑤ 拔高 | 3:10–3:50 | 150–200 | 从个案上升到产业结构或国家竞争 | “说白了，这不是一单生意，而是…” |
| ⑥ 收尾 | 3:50–4:30 | 100–150 | 社交货币 + 反问 + 关注引导 | “下次再有人跟你说…，你就把这笔账给他算一遍。” |

**再钩子密度**：全文至少 6 个（设问、悬念、反转、数字落差各至少 1 个）。

## 四、写作流程（Agent 执行顺序）

1. **事实底座**：为每个选题列出 8–15 个硬数据点，每条附 URL、发布日期、原文摘录、口径。使用研究 Agent 并行核验，未打开过的链接不得写入成稿。
2. **找反差**：在数据点里找“同时成立但看起来矛盾”的两件事（数字反差、身份反差、时间反差、空间反差）。
3. **定靶子**：写出大众最可能的误读（一句话），这是全片要打掉的东西。
4. **画钱流图**：用“谁出钱 → 经过谁 → 谁赚钱 → 谁担风险”四格先画出来，再写文案。
5. **按模板写稿**：每段标注对应画面编号（图表 / 实拍 / 资料视频）。
6. **配图表**：每期至少 4 张、图形不重复（地图路线、瀑布图、时间轴、树状/桑基、对比条、仪表数字卡）；横竖双版本；关键数字图另出 3–4 秒动画 MP4。
7. **自检**：字数 ≥ 1100；钩子 ≤ 15 秒；每个数字有出处；无“示意画面冒充现场”；结尾有社交货币。

## 五、标题公式（任选）

- 反差式：“国内 X、国外 Y，中间这笔钱谁赚了？”
- 误读式：“别再拿 39.6 亿除以 16 了”
- 身份式：“一家卖牛奶的，为什么去巴西买大豆？”
- 现场式：“我在蓬莱港边拍到一台五层楼高的锅炉，它要去阿联酋”
