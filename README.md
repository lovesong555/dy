# 六期产业链抖音中视频 · 制作包

4–5 分钟中视频版。口播文案、分镜、图表、素材链接和事实核查都在这里，可以直接开拍。

## 先看哪个

| 你要做的事 | 打开 |
|---|---|
| 看完整策划、直接读稿配音 | `六期抖音中视频_制作手册.docx`（Word，图表已嵌入）或 `六期抖音中视频_制作手册.md` |
| 把图表拖进剪映 | `图表/竖版/`（1080×1920）· `图表/横版/`（1920×1080）· `图表/动画_竖版/`（MP4 动画） |
| 批量下载素材、给剪辑师分工 | `素材链接总表.csv`（170 条 S/V/P 链接，Excel 可直接打开） |
| 第03期的照片 | `原始照片_处理版/`（已去水印、去 EXIF） |
| 查某个数字的原文出处 | `研究记录/第0X期_核查记录.md` |
| 改图表的字或数 | `图表源码/`（看里面的 README） |
| 以后写新选题 | `.claude/skills/douyin-midvideo-script/SKILL.md`（中视频文案 Skill） |
